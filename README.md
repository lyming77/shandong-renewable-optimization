# 山东电网新能源发电能力优化 —— 场站影响分析

依据《山东电网新能源发电能力优化试运行方案》实现的新能源场站影响测算模型，用于评估「超短期预测出清纳入修正机制」对场站发电计划、电量和收益的影响。

## 功能

- 上传与样例同结构的 xlsx（每个场站一个 Sheet，15 分钟点），页面录入各场站额定容量；
- 按方案内置的 **7 个试运行场景**回放触发 → 压减 → 恢复全流程；
- 输出：场站×场景汇总对比、收益/压减电量矩阵、触发/恢复事件明细、单场站单场景时序图；
- 支持下载汇总 Excel 与全量明细 CSV。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 建模口径（要点）

- 触发：出清计划值 > 额定容量×10%，且连续 2 个出清周期实际出力低于计划、偏差比例 > 触发比例（0.1 / 0.15）。
- 压减：ΔP% = β × 两个触发周期偏差比例的平均值；触发后跳过 1 个计算周期，连续压减 α 个周期的超短期预测。
- 恢复：连续 2 周期执行到位后分 γ 个周期恢复（第一次 ΔP%/2，第二次全额）；压减窗口内数据不恢复。
- 收益：压减电量(MWh) × 实时电价(元/MWh)；正价时段少发=少赚，负价时段少发=少亏。

模型实现见 `model/analyze.py`。
